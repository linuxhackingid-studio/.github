# LinuxHackingID GitHub Configuration

This repository powers the public profile for the LinuxHackingID organization on GitHub.

## Purpose

- Provide the organization profile shown at the top of the GitHub organization page
- Keep shared GitHub configuration in one place
- Present LinuxHackingID with a consistent public identity

## Included content

- `profile/README.md` for the organization profile page
- `logo/` for brand assets used by the profile (served via `raw.githubusercontent.com`)
- Shared organization-level GitHub settings and documentation, when needed

> The `.gitignore` uses an allowlist. Add a `!<path>` / `!<path>/**` entry for any new top-level folder, or it will not be tracked.

## About LinuxHackingID

LinuxHackingID is focused on Linux, hacking, security, and practical technical learning. The public profile should stay clear, useful, and aligned with that identity.

## Maintenance notes

Update the profile README whenever the organization focus changes, new projects become public, or the branding needs to be refreshed.
